This guide walks you from a fresh install to a completed Impact Report. By the end you will have connected an AI model, chosen a speech-to-text provider, recorded a meeting, reviewed the proposals the AI surfaced, and applied them to create your first versioned project state snapshot. The whole flow takes about five minutes to set up — less time than your next standup.

## From zero to first Impact Report

<Steps>
  <Step title="Download and install Clerisy">
    Download the latest `Clerisy-Setup-x.y.z.exe` from GitHub Releases and run the installer. Clerisy appears in the system tray and starts in the background. See the [Installation guide](/installation) for detailed steps, SmartScreen notes, and how to build from source.
  </Step>
  <Step title="Connect an AI model">
    Open **Settings → AI Model** and choose your provider:

    | Provider | Notes |
    |---|---|
    | **Anthropic** | Claude Sonnet (default) — strong at structured analysis |
    | **OpenAI** | GPT-4o and newer models |
    | **Google** | Gemini 2.5 Pro |
    | **OpenRouter** | Route to any model via a single key |
    | **Ollama** | Runs locally — no API key, no data sent to the cloud |
    | **OpenAI-compatible** | Any server that speaks the OpenAI API |

    Paste your API key (or base URL for Ollama / custom servers). Keys are encrypted with Windows DPAPI and stored in `secrets.json` — they never leave the main process.
  </Step>
  <Step title="Set up speech-to-text">
    Open **Settings → Transcription** and pick a provider:

    <Tabs>
      <Tab title="Local (free, recommended)">
        No API key, no upload, no cost. After a one-time **665 MB model download**, all transcription runs on your machine. Supports English and labels other participants' voices as Speaker 1, 2, and so on.

        Select **Local** and click **Download model**. The download runs in the background — you can start using Clerisy straight away and record once the model finishes installing.
      </Tab>
      <Tab title="Deepgram">
        Cloud transcription with speaker separation. Paste a Deepgram API key in **Settings → Transcription → Deepgram key**. Well-suited to meetings with multiple speakers or accents that challenge the local model.
      </Tab>
      <Tab title="OpenAI Whisper">
        Uses the OpenAI Whisper API. Reuses the OpenAI key you already entered in **Settings → AI Model** — no separate key needed.
      </Tab>
      <Tab title="Groq Whisper">
        Fast cloud transcription via Groq. Paste a Groq API key in **Settings → Transcription → Groq key**.
      </Tab>
    </Tabs>

    <Info>
      If your meetings include Hindi or Hinglish, set **Meeting language** to **Hinglish** and pick a cloud fallback — the local model is English-only.
    </Info>
  </Step>
  <Step title="Create your first project">
    Click **New project** in the sidebar, enter a name and a short description, and click **Create**. The project opens with an empty state board. Add a few requirements, decisions, or open questions so the AI has context to work with — or proceed straight to recording and build the state from your meeting.
  </Step>
  <Step title="Record a meeting">
    Start a meeting in Zoom, Teams, Google Meet, or any other app. When Clerisy detects the microphone becoming active, the floating widget offers to record. Click **Record**, or press `Ctrl+Shift+M` from anywhere on your desktop.

    The floating widget stays on top of your meeting app and shows the recording timer, the latest transcript line, and three buttons:

    - **Mark** (`Ctrl+Shift+D`) — flags an important moment; the AI weights marked moments more heavily.
    - **Stop** — ends the recording and begins transcription.
    - **Open** — brings the Clerisy window to the front.

    Press `Ctrl+Shift+M` again, or click **Stop**, when the meeting ends.

    <Tip>
      Drag the floating widget to any corner of your screen — it remembers its position between sessions. You can hide it entirely in **Settings → Recording** if you prefer the global hotkeys alone.
    </Tip>
  </Step>
  <Step title="Review the Impact Report">
    Once transcription finishes, Clerisy sends the transcript and your project state to the AI and builds an Impact Report. Open the meeting and scroll through the proposals. Each one shows:

    - **Category** — requirement, decision, action item, scope change, risk, and so on.
    - **Speaker** and **impact level** (high / medium / low).
    - **Firm or tentative** — how confident the model is that the change was agreed.
    - **Evidence** — a verbatim quote from the transcript. Click it to jump to that line.

    Accept, edit, or reject each proposal individually. Use **Accept all firm** to approve every high-confidence item in one click.
  </Step>
  <Step title="Apply changes to create a new state version">
    When you are satisfied with your selections, click **Apply**. Clerisy writes a new versioned snapshot of the project state. Open **Change history** at any time to see how the project evolved meeting by meeting, with the quotes that drove each change.
  </Step>
</Steps>

<Note>
  If you chose the **Local** speech-to-text provider, the first recording will queue for transcription until the 665 MB model finishes downloading. You will see a progress indicator on the meeting page — no action needed.
</Note>
