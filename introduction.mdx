Clerisy answers one question after every meeting: **what changed in the project because of this conversation?** It keeps a living, versioned record of your project's requirements, decisions, tasks, risks, deadlines, and open questions. After each meeting, an AI model compares the transcript against that record and proposes changes — each one backed by a verbatim quote from the transcript. You approve or reject each proposal, and the project state moves forward with a full audit trail showing who changed what, in which meeting, and exactly what was said.

## What Clerisy does

<Steps>
  <Step title="Define your project state">
    Create a project and populate the state board with your team's requirements, decisions, tasks, risks, deadlines, and open questions. Each item carries an owner, a due date, and a version number. This becomes the baseline every meeting is measured against.
  </Step>
  <Step title="Capture the meeting — no bot required">
    Start recording with `Ctrl+Shift+M` or the floating widget. Clerisy records your microphone and system audio as separate streams, so it works with Zoom, Teams, Google Meet, Slack, Discord, and any other tool you use in a browser or as a desktop app — no meeting bot to admit, no account to connect.
  </Step>
  <Step title="Transcribe automatically">
    When recording stops, Clerisy transcribes both streams. Live preview chunks appear in roughly 30-second intervals, and a final full-file pass applies consistent speaker labels across the whole conversation.
  </Step>
  <Step title="Run AI impact analysis">
    The AI model compares the full transcript against your current project state and generates a set of proposals — new items to create, existing items to update or close, scope and timeline changes, risks, blockers, and conflicts. Every proposal includes the speaker, the impact level, and whether the change is firm or tentative.
  </Step>
  <Step title="Validate the evidence">
    Every proposal must cite a real quote from the transcript. Clerisy checks each citation in code before the report is shown; proposals with no verifiable evidence are discarded automatically.
  </Step>
  <Step title="Review the Impact Report">
    The Meeting Impact Report presents only the evidence-backed proposals. Click any quote to jump to that moment in the transcript. Edit the proposal text, or accept and reject changes one by one — or use **Accept all firm** to approve the high-confidence items at once.
  </Step>
  <Step title="Apply to create a new state version">
    Click **Apply** to write a new versioned snapshot of the project state. The change history shows how the project evolved meeting by meeting, with the verbatim quotes behind every change.
  </Step>
</Steps>

## What you get

<CardGroup cols={2}>
  <Card title="Project State Board" icon="table-columns" href="/concepts/project-state">
    Typed items — requirements, decisions, tasks, risks, deadlines, open questions — each with an owner, due date, version, and a per-item history linking every change to the meeting and quote that drove it.
  </Card>
  <Card title="Meeting Impact Report" icon="file-chart-line" href="/features/impact-report">
    A structured summary of what the meeting changed: each proposal shows its category, speaker, impact level, firm or tentative status, and verbatim evidence. Clicking a quote jumps straight to that transcript line.
  </Card>
  <Card title="Ask the Project" icon="circle-question" href="/features/ask-the-project">
    Ask natural-language questions like "Why did the launch date move?" or "What's still open and who owns it?" Every point in the answer cites the project items and transcript quotes behind it. Unsupported points are left out.
  </Card>
  <Card title="Hallucination Guard" icon="shield-check" href="/concepts/impact-analysis">
    Every proposed change must quote the transcript. Citations are verified in code before the report appears; any proposal that cannot be traced back to real words is discarded before you ever see it.
  </Card>
  <Card title="Botless Capture" icon="microphone" href="/features/recording">
    Records mic and system audio as separate streams — no meeting bot, no browser extension, no account connection. Works with any conferencing tool running on your Windows machine.
  </Card>
  <Card title="Bring Your Own Model" icon="brain-circuit" href="/configuration/ai-models">
    Connect Claude, OpenAI, Gemini, OpenRouter, Ollama (local), or any OpenAI-compatible endpoint. API keys are encrypted with Windows DPAPI and never leave the main process.
  </Card>
</CardGroup>

## System requirements

| Requirement | Details |
|---|---|
| Operating system | Windows 10 or Windows 11 |
| Node.js (source builds only) | Node 22 or newer |
| Disk space for local STT | 665 MB (one-time download) |

<Note>
  Clerisy v1 is **Windows-only**. macOS support requires ScreenCaptureKit audio capture and a different microphone-usage detector, both planned for a future release.
</Note>
